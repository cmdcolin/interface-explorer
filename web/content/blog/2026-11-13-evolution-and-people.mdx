import { summary } from '../../lib/data.ts'
import { percent } from '../../lib/html.ts'
import { href } from '../../lib/site.ts'

export const s = summary()
export const patches = s.conservation.residues.patches
export const median = 'above the median patch'
export const share = p => percent(p[median].interface, p.complexes)
export const randomShare = p => percent(p[median].fake, p.complexes)
export const randoms = [patches.byInheritance.dominant, patches.byInheritance.recessive].map(randomShare)
export const bands = Object.values(patches.byConfidenceBand)
export const g = s.gnomad.byInheritance
export const ratio = x =>
  `${x['Mantel–Haenszel odds ratio'].toFixed(2)} (95% CI ${x['95% CI (bootstrap over proteins)'].join('–')}, ${x.proteins.toLocaleString()} proteins)`

Most predicted interfaces have no experimental structure to check them
against. Sequence variation offers two other checks, on very different
timescales: UCSC's phyloP, from an alignment of 100 vertebrate genomes, and the
variants gnomAD v4.1 finds in human exomes. The two disagree for recessive
genes.

**Across vertebrates.** For each confident complex we ranked the interface's
mean phyloP against same-sized patches from the rest of the protein's folded
surface. The interface ranks above the median patch in {share(patches.byInheritance.dominant)}
of complexes in dominant disease genes and {share(patches.byInheritance.recessive)}
in recessive ones. A random patch ranked the same way does in
{randoms[0] === randoms[1] ? `${randoms[0]} of both` : `${randoms[0]} and ${randoms[1]}`}. Over all complexes the share
rises with ipSAE, from {share(bands[0])} to {share(bands.at(-1))}.

**Among people.** At each interface residue we counted gnomAD's missense and
synonymous variants; the synonymous ones control for mutation rate and
coverage. Within each protein, the missense-to-synonymous ratio at the
interface, relative to the rest of the folded surface, is {ratio(g.dominant)}
in dominant genes and {ratio(g.recessive)} in recessive ones.

The interfaces of recessive genes therefore stand out in the vertebrate
record but barely among living people. Population genetics predicts this
pattern. A damaging variant in a recessive gene does no harm in a carrier, so
selection removes it slowly within a population, but over vertebrate history it
has had time to act. For browsing, gnomAD is a weak signal at the interfaces of
recessive genes.

## Caveats

- A gene counts as dominant or recessive when every disease UniProt says it
  causes has that mode in the Human Phenotype Ontology's annotations; genes
  with both modes or none are left out.
- AlphaFold reads the same alignments, so conservation supports the site, not
  the partner: a wrong partner, such as a paralog, can sit on a real conserved
  surface.
- The rest of the folded surface is constrained too, so the gnomAD differences
  are small, and phyloP scores DNA, so a codon can be conserved for splicing
  rather than for the protein.
